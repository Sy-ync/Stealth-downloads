 INSTALL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Open Chrome and go to:
     chrome://extensions

  2. Turn on Developer mode  (top right toggle)

  3. Click Load unpacked

  4. Select the StealthAI_v1.0.6 folder

  5. Open the extension popup and enter
     your license key

  Done. Press Ctrl+Shift+Z on any page.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Ctrl+Shift+Z   Capture / dismiss answer
  Esc            Cancel selection or close answer
